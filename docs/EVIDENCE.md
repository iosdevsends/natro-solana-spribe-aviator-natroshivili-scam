## How to add a new exhibit

If new evidence is added:

1. **File naming:** `exNN-short-descriptor.{png,jpg,mp4}` where NN is next sequential number (currently 14 used, next would be 15). For videos: `ex-video-NN-short-descriptor.mp4`.

2. **Optimize size:** Images should be PNG/JPG under 600KB. Videos must be H.264 720p, target <2MB. Use ffmpeg:
   ```
   ffmpeg -i source.mp4 -vf "scale='min(720,iw)':-2" -c:v libx264 -preset slow -crf 28 -c:a aac -b:a 96k -movflags +faststart -y output.mp4
   ```

3. **Add to `exhibits` object in `index.html`** (in the `<script>` section):
   ```javascript
   'exNN-short-descriptor': {
     type: 'image', // or 'video'
     src: 'images/exhibits/exNN-short-descriptor.png',
     num: 'Exhibit X',
     caption: '...'
   }
   ```

4. **Add to `exhibitOrder` array** in the right position (matches narrative flow, not filename order).

5. **Attach to timeline event** with `<a href="#" class="exhibit-thumb" data-exhibit="exNN-short-descriptor">` block.

6. **Add to §VII Evidence Gallery** grid (full thumbnail at 144px).

7. **Update this EVIDENCE.md** with full entry following the format above.
